# misc

A home for small projects, scripts, notes, and experiments.

## Getting started

Clone the repository and open its folder:

```sh
git clone https://github.com/lmbrettner/misc.git
cd misc
```

There is nothing to install yet. As projects are added, give each one its own
folder and a README explaining what it does, how to run it, and how to test it.

## Repository basics

- [`scripts/`](scripts/) holds small, standalone utilities.
- [`experiments/`](experiments/) holds exploratory projects in separate folders.
- `README.md` introduces the repository.
- `.gitignore` keeps common local files and secrets out of Git.
- `.gitattributes` normalizes text files for consistent line endings.

Keep passwords, API keys, and other credentials out of committed files. Use
environment variables or local configuration instead.
